# simulasi-k3-produksi
alur produksi presisi dari penerimaan material, CNC turning dan milling, deburring, inspeksi dimensi, pembersihan, hingga pengemasan. Materinya mengintegrasikan Hierarchy of Controls, identifikasi bahaya, pengendalian risiko, PPE, serta simulasi produk PASS/REJECT dengan animasi, hotspot, interaktif, dan audio.
